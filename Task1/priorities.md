# Приоритизация проблем

## Матрица Эйзенхауэра

|                     | **Срочно**                                         | **Не срочно**                          |
|---------------------|----------------------------------------------------|----------------------------------------|
| **Важно**           | **PR2** (риск регулятора — медданные в BI)         | PR4 (самообслуживание — цель через год) |
|                     | **PR1** (монолит блокирует всё развитие)           | PR6 (масштабирование — пока терпимо)    |

## Приоритеты MoSCoW (на 2 месяца — согласование архитектуры)

| Приоритет | Проблемы | Обоснование связи с бизнес-целями |
|-----------|----------|-----------------------------------|
| **Must have** | **PR2** (медданные в BI) <br> **PR1** (монолит) <br> **PR3** (ESB) | • PR2: без этого — потеря лицензии банка и клиник (юридический риск)<br>• PR1: без разделения доменов нельзя подключить фарма-партнёров (потеря выручки)<br>• PR3: ESB — риск остановки работы клиник (качество медсервиса) |
| **Should have** | **PR4** (самообслуживание) <br> **PR6** (масштабирование) | • Портал — ключевая цель бизнеса "через год"<br>• Масштабирование нужно для роста, но не критично в первые 2 месяца |
| **Could have** | **PR5** (размазанная логика) | Рефакторинг логики — после разделения доменов и демонтажа ESB |
| **Won't have (сейчас)** | **PR7** (изоляция надёжности) | Автоматически решится после разделения доменов (PR1) |

## Дорожная карта на 2 месяца

1. **Неделя 1-2**: 
   - Создать политику: **BI система теряет прямой доступ к DWH**
   - Выделить физические домены (Fintech, Clinics, AI) с отдельными хранилищами
   
2. **Неделя 3-4**:
   - Разработать **API Gateway / Data Mesh Control Plane**
   - Настроить авторизацию: BI портал видит только агрегаты, не медкарты

3. **Неделя 5-8**:
   - Заменить ESB на **асинхронную шину** (Kafka / Pulsar)
   - Мигрировать первый домен (Fintech) на новую архитектуру

4. **Результат к концу 2 месяца**:
   - Архитектурное решение согласовано
   - Границы доменов определены
   - План проектов по витрине данных утверждён
