| **Действия** | • Отключить прямой доступ BI к DWH<br>• Развернуть API Gateway с политиками (OPA)<br>• Создать изолированную среду для MedicalRecords<br>• Внедрить аудит всех запросов к медданным |

| **Ответственные** | Security, Infra, D&A |
| **Ресурсы** | DevOps (2 чел), Security Engineer (1 чел), $50k облачных ресурсов |
