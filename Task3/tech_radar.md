# Технологический радар «Будущее 2.0»

## Легенда
- **● Adopt** — рекомендуем к внедрению
- **▲ Trial** — пилотируем
- **○ Assess** — оцениваем
- **✖ Hold** — не используем / устарело

## Квадрант 1: Data Management & Storage

| Технология | Текущий статус | Целевой статус | Поддерживаемые бизнес-сценарии |
|------------|----------------|----------------|--------------------------------|
| SQL Server 2008 | ● Adopt | ✖ Hold (демонтаж) | Ничего нового — только legacy |
| Cloud Data Warehouse (Snowflake / BigQuery) | ✖ Hold | ● Adopt | Масштабируемая витрина данных, отчёты за минуты вместо часов |
| Data Mesh Architecture | ✖ Hold | ▲ Trial | Независимое развитие финтех и ИИ, подключение фарма-партнёров |
| Object Storage (S3) | ✖ Hold | ● Adopt | Хранение медснимков, логов моделей, дешёвое масштабирование |
| Columnar Storage (Parquet / Iceberg) | ✖ Hold | ○ Assess | Ускорение аналитических запросов по большим объёмам |
